# 设计文档模板可读性槽位 — 微测评测结果（2026-11-02）

## 协议

- **对象**：`design-doc-template.md` 的新旧两版（旧版 = HEAD 原版；新版 = 增功能卡片六字段 + 决策速览表）。对照组/实验组除模板外提示词逐字相同。
- **任务**：supercheck 命令行工具新增两功能（批量导入 + validate 子命令），需求内预埋判别点：2 个功能（测卡片）、功能一 3 种结局（测出口枚举）、2 处团队分歧（测速览表触发）。
- **样本**：全新上下文子代理各 5 次，一次性产出、无工具、无其他上下文。
- **评分**：结构闸门脚本 `check-doc-structure.sh` 的判定维度做机械核对（字段存在性 / 速览表 / 节点行数），出口枚举完整性人工对照需求预埋点。

## 结果

| 维度 | 新模板（n=5） | 旧模板（n=5） |
|------|--------------|--------------|
| 功能卡片六字段、五份同形 | **5/5，零方差** | 0/5——五份各自发明形状（结果矩阵 / 散文逐情形 / 输入→所见 bullets，各不相同） |
| 专用出口表（出口/条件/去向） | 5/5 | 0/5（出口散落在散文或矩阵中，无专表） |
| 决策速览表 | 5/5 | 0/5 |
| 一张图一个主题 | 5/5 | 2/5（3 份把两功能塞进同一张图或子图合并） |
| mermaid 节点 ≤3 行 | 5/5 | 5/5（本任务规模下未分化） |
| 出口枚举完整性（3 个预埋结局） | 5/5 | 5/5（本任务规模下未分化） |
| 决策论证质量（人工读） | 两组相当 | 两组相当 |

## 结论

1. **结构槽位有强约束力**：实验组五份收敛到同一形状、零方差；对照组五份五种形状——按「方差本身是指标」的判定标准，GREEN 达成。
2. **完整性类缺陷本次未分化**：对照组在这个小规模任务上出口枚举同样齐全。出口表漏行（重生成时实际犯过的错）是大规模/多功能文档下的失效类，模板槽位管「形状存在」，其兜底是独立审读层，不是模板——三层各管一段：闸门管结构存在性、模板管形状一致性、审读管语义完整性。
3. **阴性结果（重要）**：对照组内容质量不差，新模板未以内容质量为代价换取形状；决策论证、明确不做、自检五点两组持平。
4. **闸门自证**：五类断言变异逐一变红、真实文档全绿；过程中修掉两个闸门自身缺陷（风险章节断言在 END 处永假、加粗标记位置导致字段误判）。

## 诚实边界

- n=5/臂是微测规模，不是 AGENTS.md 要求的正式评测；单模型家族，跨 harness/模型方差未测。
- 小规模任务不触发完整性失效类，该类未在本测中获得区分证据。
- 计划模板（职责句/流程图槽位/边界条件分组）未做行为微测，由结构闸门 + 设计臂外推覆盖。

## 判定

模板改动按微测标准通过；正式评测（superpowers-evals A/B）列为后续可选项。原始样本为本会话 10 个子代理的产出全文，未落盘（会话记录可查）；本文件为结论与计分表存档。
