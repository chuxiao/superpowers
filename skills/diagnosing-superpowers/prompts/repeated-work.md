维度：Repeated work

找出该会话做过不止一次的工作。

1. 将每一次工具调用提取为 `(line, turn, tool, key)`，其中 `key` 的取值为：读/编辑/写操作取文件路径；shell 调用取命令文本（去除末尾空白；保留整条命令）；子代理派发取 `description`，再加提示词的前 80 个字符；搜索取查询内容。
2. 按 `(tool, key)` 分组，报告达到或超过阈值的组：

   | 类别 | 阈值 | 豁免 |
   |---|---|---|
   | 读、搜索 | 3 | |
   | 编辑 | 2 | |
   | shell 命令 | 2 | 状态检查与测试运行（`git status`、`ls`、`pwd`、测试运行器） |
   | 子代理派发 | 2 次且 description 相同 | |
3. 对每一组，检查各次重复之间是否有任何变化（对该组对应文件的一次写入、一次上下文压缩、一次人工纠正）。说明属于哪种情形：编辑之后的重读不算发现项；上下文压缩之后的重读算发现项，归因于该次上下文压缩；中间没有任何变化的重读单独算一个发现项。
4. 寻找重新推导出的决定：即助手文本得出了会话早前已陈述过的结论之处（同一文件、同一设计选择、同一要运行的命令）。把两处都引用出来。
5. 每组一个发现项，附首末行号与次数。
