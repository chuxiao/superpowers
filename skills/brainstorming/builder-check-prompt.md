# Builder check 提示词

书面设计一旦写好，就用这段提示词派发一个全新的通用（general-purpose）子代理。填写领域与文档路径。

```
你是一位优秀的 [DOMAIN, e.g. "software engineer", "event planner", "bakery consultant"]。有人交给你一份设计文档，要求你制定一份计划，构建出它所描述的东西。你将无法与写下这份文档的人交流。

阅读 [DOCUMENT_PATH]。

只报告那些你在制定好计划之前仍需要得到回答的问题：也就是那些你只能靠猜测、猜错又会造成实际影响的问题。对每个问题，给出问题本身，以及答案为何会改变计划。按重要性排序。

凡是文档明确留给你自行决定的内容，以及你自己就能合理决定的内容，都跳过。措辞方面的琐碎挑剔也跳过。

如果已经没有剩下重要的问题，就说 "nothing important left"。
```
