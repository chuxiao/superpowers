# 预检扫描

本文是 superpowers:subagent-driven-development 的一部分。在派发 Task 1 之前运行一次。

在派发 Task 1 之前，对计划做一次冲突扫描，边检查边记下你检查了哪些内容：

- 彼此矛盾、或与计划的全局约束（Global Constraints）相矛盾的任务
- 计划明确强制要求、而审查评分标准视为缺陷的任何内容（不做任何断言的测试、逻辑块的逐字复制）

扫描的产出是一张表，不是判定。凡共用同一文件或同一接口的一对任务，占一行：这两个任务、一方产出的内容对照另一方消费的内容、以及你发现了什么。每个任务占一行：它自己的文本是否自洽——它的验收标准逐条对照它的边界条件，它的调用示例对照它声明的 Produces 签名，它创建的文件对照它随后触碰的文件。没有这些行，所谓「扫描干净」就算不上你执行过的一次扫描。

把这张表写入台账。在执行开始前，对你发现的每一项做出裁决——每项发现都对照计划中强制规定该项内容的文本来裁决——并把每条裁决记录进台账。如果扫描干净，直接继续，不作评论。对扫描暴露出的每一处冲突做出裁决——设计文档是具有约束力的权威，计划是对它的论证——把裁决记录在扫描表中对应那一行的旁边，然后派发 Task 1。对那些只在实现阶段才会浮现的冲突，修复循环仍是兜底的安全网。
