测试不同的文档变体，找出究竟是什么促使 agent 在压力下发现并使用技能。

## 测试协议

对每个变体：

1. **先运行 NULL 基线**（无技能文档）
   - 记录 agent 选择哪个选项
   - 逐字记录 agent 给出的合理化借口

2. **在同一场景下运行变体**
   - agent 是否查看技能？
   - 如果找到技能，agent 是否使用？
   - 若有违反，记录合理化借口

3. **压力测试**——加入时间/沉没成本/权威因素
   - 压力下 agent 是否仍会查看？
   - 记录合规在何时失效

4. **元测试**——询问 agent 如何改进文档
   - "你有文档却没查看。为什么？"
   - "文档怎样才能更清晰？"

## 成功标准

**变体成功的标准：**
- agent 无需提示就主动查看技能
- agent 在行动前完整阅读技能
- agent 在压力下仍遵循技能指导
- agent 无法借合理化借口逃避遵循技能

**变体失败的标准：**
- agent 即使没有压力也不查看
- agent 不阅读技能，就凭自我理解"即兴变通"
- agent 在压力下借合理化借口逃避遵循技能
- agent 把技能当作参考资料而非要求

## 预期结果

**NULL：** agent 选择最快路径，对技能毫无感知

**变体 A：** agent 无压力时可能会查看，有压力时跳过

**变体 B：** agent 有时查看，很容易借合理化借口逃避遵循技能

**变体 C：** 合规性强，但可能显得过于僵化

**变体 D：** 该变体较为平衡，但文档更长——agent 会内化它吗？
