# 技能设计中的说服原理

## 概述

LLM 对说服原理的反应与人类相同。理解这套心理学有助于你设计出更有效的技能——不是为了操纵，而是为了确保关键实践即使在压力之下也能得到遵守。

**研究基础：** Meincke 等人（2025）在 N=28,000 段 AI 对话中检验了 7 条说服原理。说服手法使依从率翻了一倍以上（33% → 72%，p < .001）。

## 七条原理

### 1. 权威（Authority）
**定义：** 对专业知识、资历或官方来源的顺从。

**在技能中的运作方式：**
- 祈使式语言：「你必须」「绝不」「总是」
- 不可协商的措辞框架：「绝无例外」
- 消除决策疲劳与合理化借口

**何时使用：**
- 纪律约束类技能（TDD、验证要求）
- 安全攸关的实践
- 公认的最佳实践

**示例：**
```markdown
✅ 在测试之前写了代码？删掉。从头再来。绝无例外。
❌ 可行时可以考虑先写测试。
```

### 2. 承诺（Commitment）
**定义：** 与先前的行动、陈述或公开宣告保持一致。

**在技能中的运作方式：**
- 要求宣布：「宣布正在使用技能」
- 强制显式选择：「选 A、B 或 C」
- 使用跟踪机制：为清单建立待办

**何时使用：**
- 确保技能真正得到遵循
- 多步骤流程
- 问责机制

**示例：**
```markdown
✅ 找到技能时，你必须宣布：「I'm using [Skill Name]」（我正在使用 [技能名称]）
❌ 可以考虑让需求方知道你正在使用哪个技能。
```

### 3. 稀缺（Scarcity）
**定义：** 由时限或数量有限带来的紧迫感。

**在技能中的运作方式：**
- 带时限的要求：「在继续之前」
- 顺序依赖：「紧接在 X 之后」
- 防止拖延

**何时使用：**
- 即时验证要求
- 时间敏感的工作流
- 防止「我稍后再做」

**示例：**
```markdown
✅ 完成一个任务后，立即请求代码审查，然后才能继续。
❌ 你可以在方便时审查代码。
```

### 4. 社会认同（Social Proof）
**定义：** 对他人做法或公认常规的遵从。

**在技能中的运作方式：**
- 普遍模式：「每一次」「总是」
- 失败模式：「X 而无 Y = 失败」
- 确立规范

**何时使用：**
- 记录普遍实践
- 就常见失败发出警告
- 强化标准

**示例：**
```markdown
✅ 清单没有待办跟踪 = 步骤会被跳过。每一次。
❌ 有些人觉得清单配一份待办列表有帮助。
```

### 5. 同一性（Unity）
**定义：** 共享的身份认同、「我们感」、内群体归属感。

**在技能中的运作方式：**
- 协作式语言：「我们的代码库」「我们是同事」
- 共同目标：「我们都想要质量」

**何时使用：**
- 协作式工作流
- 建立团队文化
- 非层级化的实践

**示例：**
```markdown
✅ 我们是一起共事的同事。我需要你诚实的技术判断。
❌ 我错了的话，你大概应该告诉我。
```

### 6. 互惠（Reciprocity）
**定义：** 回报所受好处的义务感。

**运作方式：**
- 慎用——可能给人操纵感
- 在技能中很少需要

**何时避免：**
- 几乎总是（其他原理更有效）

### 7. 好感（Liking）
**定义：** 更偏好与自己喜欢的人合作。

**运作方式：**
- **绝不将其用于换取依从**
- 与诚实反馈的文化相冲突
- 制造谄媚

**何时避免：**
- 纪律执行场景下一律避免

## 按技能类型组合原理

| 技能类型 | 适用 | 避免 |
|------------|-----|-------|
| 纪律约束类 | 权威 + 承诺 + 社会认同 | 好感、互惠 |
| 指导/技巧类 | 适度权威 + 同一性 | 重度权威 |
| 协作类 | 同一性 + 承诺 | 权威、好感 |
| 参考类 | 仅需清晰 | 所有说服手法 |

## 为什么有效：背后的心理学

**界限分明的规则减少合理化借口：**
- 「你必须」消除决策疲劳
- 绝对化措辞消除了「这是不是例外？」一类问题
- 明确写出的反合理化对策堵住具体的漏洞

**执行意图（implementation intentions）造就自动行为：**
- 清晰的触发条件 + 必做动作 = 自动执行
- 「当 X 时，做 Y」比「一般做 Y」更有效
- 降低依从所需的认知负担

**LLM 具有类人性（parahuman）：**
- 在包含这些模式的人类文本上训练而成
- 在训练数据中，权威式语言先于依从出现
- 承诺序列（陈述 → 行动）被频繁建模
- 社会认同模式（大家都做 X）确立规范

## 伦理使用

**正当：**
- 确保关键实践得到遵守
- 创建有效的文档
- 防止可预见的失败

**不正当：**
- 为个人利益而操纵
- 制造虚假的紧迫感
- 基于内疚的依从

**检验标准：** 如果用户完全了解这套手法，它是否仍然服务于用户的真正利益？

## 研究文献

**Cialdini, R. B. (2021).** *Influence: The Psychology of Persuasion (New and Expanded).* Harper Business.
- 七条说服原理
- 影响力研究的实证基础

**Meincke, L., Shapiro, D., Duckworth, A. L., Mollick, E., Mollick, L., & Cialdini, R. (2025).** Call Me A Jerk: Persuading AI to Comply with Objectionable Requests. University of Pennsylvania.
- 在 N=28,000 段 LLM 对话中检验了 7 条原理
- 使用说服手法后，依从率从 33% 升至 72%
- 权威、承诺、稀缺最为有效
- 验证了 LLM 行为的类人（parahuman）模型

## 速查

设计技能时，自问：

1. **它属于哪种类型？**（纪律类、指导类还是参考类）
2. **我想改变的是什么行为？**
3. **哪些原理适用？**（纪律类通常用权威 + 承诺）
4. **是否组合了太多原理？**（不要七条全用）
5. **这是否合乎伦理？**（是否服务于用户的真正利益？）
